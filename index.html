Trampas del dominio

  • El guardrail de un agente reemplaza por completo al de su modelo. Si no asignas uno, hereda el del despliegue.
  • Los agentes solo admiten Annotate and block. Solo los modelos pueden usar Annotate sin bloquear.
  • Spotlighting y Groundedness se aplican a modelos, no a agentes.
  • No uses roles Cognitive Services … ni Azure AI Developer para proyectos de Foundry. La excepción es Usages Reader.
  • Un 429 no siempre es falta de cuota. Si la métrica está baja, sospecha de ráfagas o de un ajuste temporal.

IA generativa y agentes

30-35 % · domingo

Elige el tipo de agente

Prompt agent
Quiero lo más rápido, sin código de runtime.
Instrucciones, modelo y tools. Foundry lo ejecuta.
Voice-based prompt agent
Necesito voz en tiempo real sin hospedar la orquestación.
Foundry gestiona el ciclo y usa Voice Live por WebSocket.
Hosted agent
Ya tengo código en LangGraph o Agent Framework.
Tu contenedor, con endpoint, escala e identidad gestionados.
Responses API directa
Quiero que la definición viva en mi código.
Agente efímero: no creas ningún recurso de agente.

El código mínimo que debes reconocer

project = AIProjectClient(endpoint=ENDPOINT, credential=DefaultAzureCredential())

project.agents.create_version(
    agent_name="soporte",
    definition=PromptAgentDefinition(model="gpt-5-mini", instructions="..."),
)

openai = project.get_openai_client(agent_name="soporte")
conv = openai.conversations.create()                     # historial entre turnos
r = openai.responses.create(conversation=conv.id, input="Hola")
print(r.output_text)

Si ves threads, runs o azure-ai-projects 1.x, es la API clásica. El parámetro model recibe el nombre del despliegue.

Optimizar y observar

AjusteInstrucciones claras, ejemplos, salida estructurada. Cambia temperature o top_p, no ambos.
ReflexiónGenerar, criticar y revisar. Puede ser un segundo agente evaluador o un bucle limitado.
ObservabilidadConecta Application Insights y revisa trazas, tokens, señales de seguridad y latencia por paso.
OrquestaciónCombina varios modelos y reglas: lo determinista va en código, lo ambiguo en el LLM.

Trampas del dominio

  • allowed_tools=[] permite todas las herramientas del servidor MCP, no ninguna.
  • Function calling no ejecuta nada por sí solo. Tu app devuelve el resultado al modelo.
  • Memory es para lo aprendido del usuario, no para documentos corporativos.
  • La evaluación a nivel de conversación exige datos en formato messages.
  • Si la tarea cabe en una función normal, no necesitas un agente.

Content Understanding para visión

Single-task, el modo standard, procesa un archivo por tarea. Pro mode razonaba en varios pasos sobre documentos y referencias. Esa versión preview se retiró, y su sucesor es agentic mode en 2026-06-01-preview. Pro mode sigue en el temario, así que entiende la diferencia conceptual.

Para video usa prebuilt-videoSearch: segmenta por escenas, transcribe y describe cada segmento.

Trampas del dominio

  • dall-e-3 se retiró el 4 de marzo de 2026. Una opción con DALL·E probablemente sea el distractor.
  • Sora rechaza imágenes de entrada con rostros humanos y no genera personas reales.
  • El texto dentro de una imagen puede ser una inyección indirecta. Trátalo como contenido no confiable.
  • Para procedencia, piensa en marcas y Content Credentials, no en filtros de contenido.

Escalera de búsqueda

KeywordBM25. Ideal para códigos, nombres y fechas.
VectorSimilitud de concepto, con HNSW o eKNN.
HybridAmbas en una solicitud, fusionadas con RRF.
SemanticReranking L2 con queryType: semantic.
Agentic retrievalDivide en subconsultas, las ejecuta en paralelo y une resultados.
{ "search": "garantía del modelo X200",
  "vectorQueries": [{"kind":"vector","vector":[...],"fields":"contentVector","k":50}],
  "queryType": "semantic",
  "semanticConfiguration": "cfg" }

Con semantic ranker usa k=50 para darle suficientes candidatos. Agentic retrieval requiere knowledge base y knowledge source. Su reasoning effort puede ser minimal, low (predeterminado) o medium. minimal omite la planificación; lo que usa LLM para planificar sigue en preview.

Trampas del dominio

  • El método Extract solo funciona con documentos. Para video o audio usa Generate o Classify.
  • Confianza y grounding se activan con estimateFieldSourceAndConfidence.
  • Si cambias el modelo de embeddings debes vectorizar de nuevo todo el índice.
  • Markdown sirve para RAG y razonamiento. JSON sirve para automatización.
  • En producción copia el prebuilt: su definición puede cambiar entre versiones de API.
  • Usa orderby con cuidado: anula el orden por relevancia.

Por qué pueden diferir algunos nombres

El temario es del 16 de abril de 2026 y Foundry ha cambiado desde entonces. Si el examen usa Azure AI User, equivale a Foundry User. Si menciona pro mode o workflows, responde según el concepto. Microsoft indica que casi todas las preguntas cubren funciones GA, pero puede incluir preview si es de uso común. Las versiones traducidas se actualizan unas ocho semanas después de la inglesa.
