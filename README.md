# Guía de Preparación AI-103

Curso interactivo para preparar el examen AI-103, *Developing AI Apps and Agents on Azure*, en 4 o 5 días.

Organizado en cinco módulos y 29 lecciones. Cada lección abre con una analogía e incluye concepto con esquemas integrados, explicación a fondo, ejemplo con un caso continuo, errores frecuentes, práctica y preguntas con formato de certificación. También ofrece un examen de práctica de 120 minutos con casos de estudio, además de tarjetas de repaso.

El módulo 4 incluye un bloque de RAG a fondo: chunking y vectores, generación con grounding y citas, permisos por documento, y evaluación y optimización.

El contenido sigue el temario oficial publicado por Microsoft. Las preguntas son originales y no provienen del examen real. Este proyecto no está afiliado a Microsoft.

El progreso se guarda únicamente en el navegador. Para uso local, abra `index.html`.
